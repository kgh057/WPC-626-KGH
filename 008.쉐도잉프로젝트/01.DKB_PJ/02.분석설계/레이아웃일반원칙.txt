[ 레이아웃 일반원칙 ]

제1원칙 : 큰 영역은 div로 잡는다

제2원칙 : 내부 컨텐츠영역은 시멘틱태그로 잡는다

- 시멘틱 부칙 : 
    2-1. 상단영역 header
    2-2. 하단영역 footer
    2-3. 일반구분영역 section 
    2-4. 제목과 내용이 들어가는 세부영역 article : 독립적인, 기사 
    2-5. 네비게이션영역 navigation(nav)
    2-6. 메인컨텐츠 영역 main (한번만 사용)

제3원칙 : 내부 파티션(내용 구분) 박스는 div를 사용한다 -> 내부 칸막이

제4원칙 : 상세내용 박스는 아래와 같이 구조화한다
    4-1. 묶음내용은 그룹핑 요소 사용 : ul/li, ol/li
    4-2. 제목 성격은 헤딩요소 사용 : h1 ~ h6
    4-3. 인라인 내용은 단락요소 사용 : p (내부 블록 불가) 
    -> 순수하게 글자, 이미지 글자
    -> 안에 ul/li, div 불가
    4-4. 의미를 나름 부여하여 여러요소 사용 : address, span
